# 🪴 Garden Dashboard (sowftware)

> **Local-first garden & crop management dashboard — planting schedules, harvest tracking, task planner and offline support. Powered by IndexedDB and PWA capabilities.**

Une application web moderne et progressive (PWA) conçue pour planifier, suivre et gérer votre potager / jardin en toute autonomie, sans dépendance à un serveur distant.

---

## ✨ Fonctionnalités Principales

- 📅 **Calendrier de semis & plantations** : Suivez les périodes idéales pour semer, planter et récolter vos cultures.
- 🧺 **Suivi des récoltes & tâches** : Organisez vos entretiens quotidiens et gardez un historique de votre rendement.
- 📱 **PWA & Mode Hors-Ligne** : Installable sur mobile et ordinateur, utilisable même au fond du jardin sans connexion Internet.
- 🔒 **100% Local-First** : Vos données restent chez vous, stockées directement dans votre navigateur via IndexedDB.
- 🚀 **Interface fluide & réactive** : Navigation rapide sans rechargement de page et état centralisé.

---

## 🛠️ Stack Technique

- **Bibliothèque principale** : [React 19](https://react.dev/)
- **Tooling & Build** : [Vite 8](https://vitejs.dev/)
- **Langage** : [TypeScript](https://www.typescriptlang.org/)
- **Styles** : [Tailwind CSS v4](https://tailwindcss.com/)
- **Gestion d'état** : [Zustand](https://zustand-demo.pmnd.rs/)
- **Routage** : [React Router v7](https://reactrouter.com/)
- **Stockage local** : [idb](https://github.com/jakearchibald/idb) (IndexedDB Wrapper)
- **Support PWA** : `vite-plugin-pwa`
- **Icônes** : Lucide React
